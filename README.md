# ollie-storybook/

My stories website! All my books and videos live here.

This is a git submodule - it has its own repo.

---

## What This Folder Is For

Publishing my stories for people to read. This is the REAL website.

---

## Folders

| Folder | What's Inside |
|--------|---------------|
| `stories/` | HTML pages for each story |
| `images/` | Pictures for the stories (subfolders per story) |
| `book-images/` | Extra pictures I made |
| `videos/` | My videos |
| `css/` | Makes things pretty |
| `fun/` | Fun stuff page |
| `about/` | About me page |

## When to Save Here

- New story pages go in `stories/`
- Story images go in `images/[story-name]/`
- Videos go in `videos/`

---

## Don't Save

- `prompts.json` files - delete these (they're generator junk)
- `index.html` gallery files - auto-generated, can delete
